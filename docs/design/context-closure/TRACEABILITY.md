# Molecular traceability projection

> **N-class only.** This index records known links and explicit gaps. It does not replace GitHub, Git, runtime receipts, or executable evidence.

## Trace unit

Every molecular implementation should be reconstructable as:

```text
source requirement or observed problem
  -> stable requirement / bounded hypothesis
  -> exact GitHub Issue
  -> dependency and write-boundary admission
  -> Noodle order / session / registered worktree
  -> PR and exact candidate head
  -> changed paths
  -> positive + planted-negative + non-case controls
  -> physical oracle / direct readback / residue
  -> trusted verification receipt
  -> merge/default-branch/Issue-closure readback
  -> local reconciliation
```

Use `TRACEABILITY_GAP` for any missing link. Never infer a SHA, receipt, session, or provider event.
