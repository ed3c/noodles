## Update procedure

1. Freeze one exact Git commit and tree.
2. Fetch the complete current Issue and PR denominators. Record the endpoint, provider timestamp, and ETag. Mark the refresh `ABSENT` if either query fails.
3. Read current repository paths instead of copying status from this package.
4. Keep inaccessible owner, image, article, and PDF sources in the denominator.
5. Compile separate start-readiness and completion-readiness edges.
6. Assign one problem owner and one convergence owner. Record overlaps in `DRIFT.md`.
7. Update all six files in one atom.
8. Verify that only these files changed.
9. Run the existing N-class evidence negative, document controls, repository baseline, direct path readback, and residue check.
10. Re-read provider facts before any action that depends on current Issue, PR, head, check, merge, or closure state.
