## Closure states

| State | Meaning in this projection |

| `CLOSED` | The owner problem's stated denominator has an exact physical/provider evidence lane and no known residual in that bounded scope. |

## Closure principles

1. A leaf Issue closes only its exact claim.
2. A global objective closes only when its declared case/journey denominator is reconciled.
3. `tests pass`, a Skill route, an architecture document, or a closed Issue is never enough by itself.
4. Provider landing cannot upgrade a claim beyond the candidate's actual L evidence.
5. An inaccessible case remains in the denominator as `ABSENT` or `BLOCKED`.
6. A successor may start from a stable interface while still being completion-blocked on the predecessor's R receipt; `DAG.md` records both edges.
