## Closure rule

A row closes only when its own denominator is complete. `Issue closed`, `PR merged`, `tests green`, or `Agent says done` is insufficient when the row names a wider runtime/product/provider requirement.

## Known denominator limits

- Raw owner conversation remains outside repository storage; this package is a bounded projection, not complete transcript persistence.
- Article/PDF/social claims remain external unless a dedicated evidence atom verifies them.
- Repository-wide semantic duplicate-owner detection is not yet a proven mechanical seam.
- Requirement-status projection is intentionally not implemented; all status above is timestamped N projection and must be provider-re-read before use.
